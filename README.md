# Milestone Renovate

Premium Australian renovation website and enquiry platform for **Milestone Renovate**, renovation brand of Milestone Development,
live at https://milestonerenovate.com.

- **Stack:** 22 static pages (21 indexed + 404) generated by a Python script (`build_site.py`) into `public/`, vanilla
  JS modules, two Vercel functions (`/api/enquiries`, `/api/notifications/retry` on a daily cron), Supabase Postgres
  (Sydney) for enquiries and Resend for staff email. No framework.
- **Identity:** primary forest `#0F201D`, secondary forest `#2A5A4F`, logo gold `#DDB45C`, cream/sage surfaces;
  Newsreader + Inter, self-hosted. Details in [DESIGN.md](DESIGN.md).
- **Current verified status, test evidence and open items:** [docs/STATUS.md](docs/STATUS.md).
- Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · Operations: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) ·
  Roadmap: [docs/IMPLEMENTATION-ROADMAP.md](docs/IMPLEMENTATION-ROADMAP.md) · Pricing: [docs/PRICING-METHODOLOGY.md](docs/PRICING-METHODOLOGY.md).

## Develop

```bash
npm install
npm run dev          # http://127.0.0.1:8765 — leads go to an IN-MEMORY store (dev only, nothing persisted or emailed)
npm run build:site   # regenerate public/*.html from build_site.py
npm run build:brand  # regenerate favicons / OG image from the logo pack
npm run build:team   # regenerate responsive team portrait variants from assets/team/
```

Edit page content in `build_site.py`, then rebuild. Styles live in `public/css`, behaviour in `public/js`.

## Test

```bash
npm test             # unit + integration (service, handler, real-migration RLS on PGlite, wizard, client, planner)
npm run test:e2e     # Playwright against the dev server using installed Chrome
npm run audit        # production dependency audit
DEPLOYED_URL=https://milestonerenovate.com npx playwright test tests/e2e/deployed.spec.js   # read-only production checks
```

The e2e suite reads the private PNG image masters from `incoming-images/` (git-ignored) only where they exist; in a fresh
clone or CI those two master checks are skipped and the committed WebP/AVIF variants are still validated. The
`integration.spec.js` live-pipeline test is opt-in (`INTEGRATION=1`) because it creates real leads and sends real email.

## Configure production (Vercel project → Environment Variables)

Copy `.env.example` for the full list. Required for enquiries to work: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`,
`IP_HASH_SECRET`. Optional (staff emails): `RESEND_API_KEY`, `NOTIFY_TO_EMAIL`, `NOTIFY_FROM_EMAIL`.
Apply `supabase/migrations/*.sql` to the Supabase project. Without configuration the API returns `503 not_configured`
(it never pretends to save).
